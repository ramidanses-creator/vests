# מעקב הזמנות ורווחים

אפליקציית ווב למעקב אחרי מוצרים מיובאים: לכל מוצר רושמים את כמות הייבוא ואת כל ההוצאות עד ההגעה לארץ (עלות רכישה, משלוח, מכס וכו׳), ולאחר מכן רושמים את המכירות (כמות ומחיר ליחידה). האפליקציה מחשבת אוטומטית:

- עלות ליחידה (סה״כ הוצאות חלקי כמות שיובאה)
- כמות שנמכרה וכמות שנותרה במלאי
- הכנסות ורווח כולל, ורווח ליחידה
- סיכום כללי על פני כל המוצרים

הנתונים נשמרים בדפדפן (localStorage).

## הרצה

```bash
npm install
npm run dev
```
