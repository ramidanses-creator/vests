# פנקס — קבלות וחשבוניות

אפליקציית ווב (מותאמת לנייד, ניתנת להתקנה כ־PWA) להפקת מסמכי הכנסה ולמעקב הוצאות לעסק קטן.

## מה יש בה

- **דף בית** — ברכה, חיובים פתוחים, תקבולים החודש, טיוטות, פעולות מהירות וסיכום הכנסות/הוצאות לשבוע, 30 יום או שנה.
- **הפקת מסמכים** (כפתור ה־+):
  - מסמכי הכנסות: חשבונית מס, חשבונית מס/קבלה, חשבונית זיכוי, קבלה
  - מסמכי ניהול שוטף: חשבון עסקה, הצעת מחיר
  - מספור רץ נפרד לכל סוג מסמך (אפשר להגדיר מספר התחלתי), מע״מ כלול/לא כלול, הנחה, פיצול לכמה אמצעי תשלום (מזומן, אשראי בתשלומים, Bit, PayBox, Apple Pay, Google Pay, העברה, צ׳ק)
  - שדה **מספר הקצאה** מופיע אוטומטית בחשבונית מס ללקוח עוסק מעל הסף (ברירת מחדל 5,000 ₪ לפני מע״מ, ניתן לשינוי בהגדרות)
  - מסמך שהופק נעול לעריכה; תיקון נעשה בחשבונית זיכוי
  - מתוך מסמך: הפקת קבלה על חשבונית פתוחה (סוגרת אותה אוטומטית), המרת הצעת מחיר לחשבונית, זיכוי, שכפול
  - הדפסה / שמירה כ־PDF בפורמט A4, שליחה בוואטסאפ, במייל או בשיתוף
- **לקוחות** — נשמרים אוטומטית בהפקה, עם יתרה פתוחה והיסטוריית מסמכים.
- **הוצאות** — צילום, גלריה, קובץ PDF או ללא קובץ; חישוב מע״מ תשומות וקטגוריות.
- **דוחות** — דוח הכנסות ודוח הוצאות חודשי/שנתי, סיכום מע״מ, ייצוא CSV (נפתח באקסל) ושליחה לרו״ח.
- **סוג עוסק** — מורשה / פטור / חברה. לעוסק פטור מוצגים רק קבלה, חשבון עסקה והצעת מחיר, ללא מע״מ.

## חשבון וגיבוי בענן

- כניסה עם אימייל וסיסמה (Firebase Authentication — אותו פרויקט Firebase של אפליקציית המעקב), כולל איפוס סיסמה.
- כל לקוח, מסמך והוצאה נשמרים כמסמך נפרד ב־Firestore תחת `users/{uid}/pinkas`, ותמונות הקבלות תחת `users/{uid}/pinkas_files` (עד ~700KB לקובץ).
- נכנסים מכל מכשיר — הנתונים מגיעים מהענן ומתעדכנים בזמן אמת. עבודה בלי אינטרנט נשמרת במכשיר ועולה כשהחיבור חוזר.
- נתונים שנשמרו במכשיר לפני שהיו חשבונות עוברים לחשבון הראשון שמתחבר בו.
- מצב הגיבוי מוצג בנקודה ליד העיגול בדף הבית ובמסך "פרטי העסק".

### חוקי אבטחה ב־Firestore

כדי שכל משתמש יוכל לקרוא ולכתוב רק את הנתונים שלו, החוקים ב־Firebase Console → Firestore Database → Rules צריכים לכלול:

```
match /users/{userId}/{document=**} {
  allow read, write: if request.auth != null && request.auth.uid == userId;
}
```

(בתוך `service cloud.firestore { match /databases/{database}/documents { ... } }`, לצד החוקים הקיימים של אפליקציית המעקב.)

## הרצה

```bash
cd invoices
npm install
npm run dev     # פיתוח
npm test        # בדיקות
npm run build   # בנייה ל-dist
```

באתר GitHub Pages של הריפו האפליקציה נבנית לנתיב `/invoices/`.

## חשוב לדעת

זו אינה "תוכנה מאושרת" לפי הוראות ניהול ספרים של רשות המסים, והיא לא מקבלת מספרי הקצאה אוטומטית (את המספר מקבלים באזור האישי באתר רשות המסים ומקלידים). לפני שימוש כמערכת ההנהלה הרשמית של העסק, כדאי לבדוק עם רו״ח.
